### Mandatory Design DNA & Architectural Standards:

1. **Aesthetic & Color System**:
   - Ultra-premium dark glassmorphism theme (`#080D1A` deep midnight navy background).
   - Radiant high-contrast accents (electric cyan `#00F0FF`, emerald `#10B981`, or gold `#F59E0B`).
   - Frosted glass cards with `backdrop-filter: blur(16px)`, translucent background `rgba(255, 255, 255, 0.04)`, and delicate 1px border `rgba(255, 255, 255, 0.08)`.
   - Crisp modern typography (Inter / Plus Jakarta Sans) with generous spacing and anti-clutter discipline.

2. **Hero Stage (The 3D Zooming Engine & Live Ticker)**:
   - **Continuous 3D Zooming Background**: An immersive high-resolution hero photo set in a 3D perspective stage with continuous slow camera keyframe zoom, glare lighting plane, and subtle interactive mouse/device tilt.
   - **Moving Number Cards**: A dynamic metrics strip with continuously ticking number cards (e.g., 5.0★ Rating, 100% Satisfaction, 24/7 Availability, 30-Min Rapid Response) that decelerate smoothly and lock permanently onto target numbers when scrolled into view.
   - **Dual Immediate CTAs**: Prominent "Call Now" tap-to-call button + "WhatsApp Quote" button with prefilled message.

3. **About & Benchmark Section (Cards & Pointers, Zero Wall of Text)**:
   - Break company capabilities into digestible grid cards with glowing icons and 3-4 bullet points each (e.g., Industrial Grade Equipment, Certified Background-Checked Staff, Eco-Safe Solutions, Transparent Pricing).
   - Include a dedicated **Interactive Google Map Card** showing live status badge ("Open Now"), full address, distance badge, and a 1-click "Get Directions" link opening Google Maps.

4. **Why Choose Us & Interactive Before / After Comparison**:
   - Interactive Before & After comparison slider with an interactive draggable handle (or responsive side-by-side interactive toggles) showcasing real service results.
   - Supporting credibility badges (e.g., On-Time Guarantee, Insured & Verified, Zero Hidden Fees).

5. **Services Section**:
   - Grid of service cards with category tags, bulleted feature checklists, duration/scope indicators, and an instant "Book on WhatsApp" button that pre-fills the specific service title in the chat.

6. **Verbatim Google Reviews Showcase**:
   - Google Review badge with verified 5.0 star rating, authentic reviewer avatars/initials, verbatim quotes, and a direct link to "Write a Google Review" or "View on Google Maps".

7. **Persistent Floating Conversion Dock**:
   - Fixed bottom-right or mobile bottom-bar featuring instant **Tap-to-Call** (`tel:...`) and **WhatsApp** (`https://wa.me/...`) buttons with pulse animations so visitors can convert at any point on the page.

8. **Engineering & SEO**:
   - Fully responsive across mobile, tablet, and widescreen.
   - Open Graph metadata, semantic HTML5, zero broken links, smooth scroll behavior.

## 🎨 Quick Reference: Design Tokens

If customizing CSS or Tailwind manually, use these core tokens to match this site's exact look:

| Element | Specification / Token |
| :--- | :--- |
| **Background Base** | `#070b14` / `bg-slate-950` with subtle radial radial-gradient mesh |
| **Surface Card** | `background: rgba(15, 23, 42, 0.65); backdrop-filter: blur(14px); border: 1px solid rgba(255, 255, 255, 0.08);` |
| **Card Hover** | `border-color: rgba(0, 240, 255, 0.35); transform: translateY(-4px); box-shadow: 0 12px 30px rgba(0, 240, 255, 0.08);` |
| **Primary Accent** | Electric Cyan `#00F0FF` / Vivid Blue `#2563EB` |
| **Success Accent** | Emerald Green `#10B981` (used for verified reviews, 24/7 status badges, WhatsApp) |
| **Gold Star Accent** | `#F59E0B` / `#FBBF24` (Google review stars) |
| **Headings Font** | `Plus Jakarta Sans` or `Inter`, font-weight 700 / 800 with tight letter-spacing (`-0.02em`) |
| **Body Font** | `Inter`, font-weight 400 / 500, color `#94A3B8` (slate-400) |
| **CTAs** | Pill or rounded-xl buttons with subtle gradient (`linear-gradient(135deg, #2563EB, #00D2FF)`), soft glow shadow |
